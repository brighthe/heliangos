# 微信归档与事实路由

1. 完整读取 [ai/wechat-workflow.md](../../../ai/wechat-workflow.md) 并严格执行其数据模型、定位、归档、索引、路由和引用规则。
2. 按 frontmatter 的 `person` 在 `wechat/contacts/` 定位联系人；结果不唯一或新联系人场景不明时先询问。
3. 忠实转写并去重追加，只保存文字；用户已发送的内容以实际发送版本为准。
4. 更新人物信息、沟通口径和沟通层未决；新建联系人或映射变化时同步两个索引。
5. 归属明确时读取目标仓库规则并同步派生事实；有歧义、目标缺失或工作树冲突时停止对应写入并报告。
6. 不操作微信，不自动 commit 或 push。完成后报告聊天增量、联系人与索引更新、外部事实源更新和未执行项。
