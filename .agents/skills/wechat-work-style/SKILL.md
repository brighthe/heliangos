# 微信工作沟通家族写作风格（wechat-work-style）

起草或修改给老师/工作对象的微信回复时遵循本风格，使草稿读起来像「得体、靠谱的真人何亮」在打字，而不是 AI 或公文。

> 基础硬规则（全中文口语、不在回复正文用 Markdown、对老师用「您」、先回应核心诉求、承诺留余地）见 [AGENTS.md](../../../AGENTS.md)「写作约定」。本手册只补 AGENTS.md 说不清的**隐性手感**。

## 1. 语气与视角

- **谦逊但有条理**：面对老师，姿态低、信息密度高。先表态/回应，再补细节，别让老师猜。
- 解释「我会怎么做」而不是只说「好的」：让对方有掌控感（如"我先把 A 弄完，最晚周三给您"）。
- 真诚优先于客套：客气一两句即可，重点放在把事说清楚。避免堆砌"非常感谢您百忙之中…"这类空话。

## 2. 分段节奏（微信特有手感）

- **短句、分行**，一条消息别写成一大段。复杂事项拆成 2–3 行的小节奏，像真人连发。
- 关键结论放最前或单独一行，方便老师扫一眼就抓到重点。
- **不要 Markdown**：发出去的内容没有 `#`、`-`、表格、代码块。给我看的草稿可以用「方案 A / 方案 B」分隔，但标明哪部分是要发的正文。

## 3. 称呼与敬语

- 对老师一律「您」；称呼用各老师档案里记录的习惯（`wechat/大连理工大学博士后/teachers/<老师>.md` 的"称呼"字段）。拿不准标「称呼待确认」。
- 开头称呼 + 视情况一句寒暄/回应；结尾可「麻烦您了」「谢谢老师」，但不过度。
- 不同熟络度调松紧：初识更端正，熟络可略轻松，但对老师始终留礼数。

## 4. 软化与分寸技巧

- **拒绝/为难**：先共情或给理由，再婉拒，并给替代方案——「这周确实排满了，要不我周一先给您一版初稿？」胜过直接「不行」。
- **坏消息/延期**：先担责 + 给新时间点 + 简短补救，不辩解、不甩锅。
- **答应**：把交付条件说清（什么时候、什么范围、需要老师给什么），避免日后扯皮。
- **催老师/提醒**：给台阶，用"不知道您那边方不方便""还麻烦您有空时…"，不显催促。
- 适度软化词「哈」「~」「👌」「🙏」可用，但**对正式事项、坏消息、不熟的老师克制**，宁少勿滥。

## 5. 结构（默认套路）

一条好的回复 = **回应老师核心诉求 → 我的处理/答复 →（必要时）下一步或确认项**。先回应，再展开；需要老师拍板的，把选项列清并给出我的建议。

## 6. 改动纪律

- 不确定的事实（时间、是否答应、对他人评价）**不要替我编造**，标「待确认」。
- 涉及承诺/金额/报销/推荐/署名等敏感事，措辞从严、留余地；必要时建议调用 `reply-reviewer` 复核。
- 口径以各老师档案与 `profile/about-me.md` 为准，全仓库保持一致。
