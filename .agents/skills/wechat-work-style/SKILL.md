# 微信工作沟通风格

1. 完整读取 [ai/wechat-writing-style.md](../../../ai/wechat-writing-style.md) 并按其共享规则起草或审阅。
2. 按 [微信归档与事实路由工作流](../../../ai/wechat-workflow.md) 在 `wechat/contacts/` 定位联系人，读取称呼、熟络程度、沟通口径和近期聊天。
3. 必要时读取 `profile/about-me.md`；不确定的事实、承诺或称呼标“待确认”，不要编造。
4. 实际发送正文使用自然中文短句，不使用 Markdown 标题、表格或代码块。
5. 用户已经发送消息时，以实际发送版本为准，不用此前未发送草稿覆盖。
6. 只提供草稿或审阅意见，不操作微信，不替用户发送。
