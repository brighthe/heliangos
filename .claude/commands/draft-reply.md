帮我起草一条给指定联系人发送的微信回复。

联系人与消息：$ARGUMENTS

若上面为空，则使用我在本会话中最近粘贴的消息。

步骤：

1. **认人**：按 [微信归档与事实路由工作流](../../ai/wechat-workflow.md)，根据 frontmatter 的 `person` 在 `wechat/contacts/` 定位目标，读取其 YAML 元数据、人物档案、沟通口径与近期聊天；必要时读 `profile/about-me.md`。同名或场景不明时先确认；尚未建档时提示建档，并先凭消息本身起草。
2. **拆来意**：若对方来意不直白、夹带请求、或不确定该不该答应，先用 `intent-analyst` 子代理拆解；简单消息可跳过。
3. **起草**：按 `wechat-work-style` 技能与 [微信工作沟通写作风格](../../ai/wechat-writing-style.md) 起草——称呼依档案，对老师用「您」，先回应核心诉求再展开，承诺留余地。给我 **1–2 版**可直接发的草稿（像真人微信打字，不要 Markdown 标题/表格）。
4. **标注**：称呼、关键事实、是否答应等拿不准处标「待确认」，不要替我编造。

**只产出草稿，不要尝试代我发送或操作微信。** 发送由我自己来。
