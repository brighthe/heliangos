使用 `wechat-log-and-route` 技能，把我粘贴的微信聊天（**截图或文字皆可**）归档到对应联系人，并同步明确形成的领域事实。**只存文字，不保存截图。**

联系人与聊天内容：$ARGUMENTS

步骤：

1. 完整读取 [微信归档与事实路由工作流](../../ai/wechat-workflow.md)。
2. 按 frontmatter 的 `person` 在 `wechat/contacts/` 中定位联系人；同名、未建档或场景不明时先向我确认。新建联系人时复制统一模板，并同步两个联系人索引。
3. 忠实转写、按日期去重追加；不确定的日期或文字标“待确认”，不要编造。用户已发送的内容以实际发送版本为准，只有我明确要求时才脱敏。
4. 更新联系人档案中的人物信息、沟通口径和沟通层未决；`contexts` 或 `related_repositories` 变化时同步索引。
5. 判断是否形成行政、项目、科研、软件或工具事实；归属明确时读取目标仓库规则并自动同步，归属不明或目标有冲突时只报告并询问。
6. 回报新增条数、时间范围、联系人与索引更新、派生事实源更新和未执行项。

不要操作微信，不要保存原始截图，不要自动 commit 或 push。
