# heliangos 通用上下文（所有 AI 共享）

> 本文件是 heliangos 仓库对**所有 AI 助手**（Claude Code / Codex / Antigravity 等）通用的工作上下文，是这些内容的**唯一来源**。各 AI 的运行时专属细节（配置位置、Hook 实现）见 [ai/claude/CLAUDE.md](../claude/CLAUDE.md) 或 [ai/agents/AGENTS.md](../agents/AGENTS.md)；根目录 [CLAUDE.md](../../CLAUDE.md) / [AGENTS.md](../../AGENTS.md) 是指向它们的桩。

**`heliangos` 是 Liang He（何亮 / brighthe）的「个人中枢」仓库，不是代码项目。** 核心工作是帮我组织个人上下文、并基于这些上下文协助我处理对外沟通（当前重点：微信回复）。

## 仓库定位

把「我是谁、我和谁打交道、我们聊过什么」沉淀成结构化、可被 AI 读取的上下文，让 AI 在协助我写东西、回消息、做决定时**有据可依**，而不是每次从零解释。

**它是渐进式的**：架构会随需要生长。当前已落地的模块见下；新增模块时，在根目录开一个语义清晰的文件夹，并在 [README.md](../../README.md) 与本文件登记。

## 微信模块工作方式

详见 [wechat/README.md](../../wechat/README.md)。聊天记录按阶段分子模块归档，当前子模块有：[wechat/dalian-university-of-technology-postdoc/](../../wechat/dalian-university-of-technology-postdoc/)（我在大工做博士后期间与相关老师的沟通，按老师分档）、[wechat/xiangtan-university-phd/](../../wechat/xiangtan-university-phd/)（我在湘潭大学攻读博士期间与导师、老师、同门、同事等的沟通，按联系人分档）、[wechat/高校求职/](../../wechat/高校求职/)（我求职高校教职期间与各校的沟通，先按学校分文件夹、校内再按联系人分档；目标校：湖南理工大学、湖南工程学院、长沙师范学院、湖南警察学院）。要点：

1. **每位老师/联系人一个文件**：大工博士后用 `wechat/dalian-university-of-technology-postdoc/teachers/<姓名>.md`，湘潭大学博士和高校求职等更宽泛场景用 `contacts/<姓名>.md`；均含「人物档案 + 关键信息 + 当前未决 + 聊天记录」。
2. **记录聊天（我发截图，你只存文字）**：我把与老师/联系人的微信**聊天截图**（或文字）发给你，用 `/log-chat <姓名>` 转写成文字、按时间去重追加到对应文件，并据此更新档案。**只存文字，不保存截图**；不要用 computer-use 去驱动微信（既慢又会被其他窗口抢焦点）。
3. **起草回复（只起草，我自己发）**：我把老师/联系人消息发给你（或它已在聊天记录里）；你先读对应档案与历史，再用 `/draft-reply` 起草草稿，**由我亲自发送**。

## 写作约定（对外沟通，尤其微信工作沟通）

- **语言**：全中文，口语自然。微信回复不是邮件公文，避免「兹」「特此」「敬悉」这类书面腔。
- **分段**：按微信习惯短句、分条。**发出去的回复正文不要用 Markdown 标题/表格/代码块**，要像真人打字。
- **称呼与敬语**：对老师一律用「您」，称呼跟随对方既有习惯（见各老师档案的"称呼"字段）；拿不准标注「称呼待确认」。
- **分寸**：尤其面对导师/合作老师——能答应爽快答应；不能答应先共情再说明、给替代方案；涉及时间/承诺/责任的措辞留有余地，不留把柄。
- **结构**：先回应对方核心诉求，再展开，必要时给确认项。

## 可用的高级功能（各 AI 均已配备）

- **技能（自动触发）**：`wechat-work-style`（微信工作沟通家族写作风格）。
- **子代理（委派）**：`intent-analyst`（拆解老师消息的真实来意）、`reply-reviewer`（回复草稿得体性深审，只读产出清单）。
- **斜杠命令/常用维护**：
  - `/log-chat`（把我粘贴的聊天截图/文字转写归档）
  - `/draft-reply`（起草回复）
  - `/sync-obsidian`（检查 Git 状态干净后，自动运行根目录 `Sync-ToObsidian.ps1` 将仓库增量同步至 iCloud Obsidian）

> 各 AI 的配置**存放位置**与 **Hook 具体实现路径**不同，见其专属文件（[ai/claude/CLAUDE.md](../claude/CLAUDE.md) / [ai/agents/AGENTS.md](../agents/AGENTS.md)）。**修改能力（技能/子代理/命令/hook）时，各运行时的副本需手工同步**（不会自动同步）。

## 安全硬约束：不驱动微信

本仓库的工作方式是「我发截图/文字，你只产出文本」，AI **不**驱动微信。作为防御性硬约束，各运行时都配置了 `PreToolUse` 钩子，由 `block-wechat-automation.ps1` 拦截 computer-use 的键盘输入与批量动作（`type`/`key`/`hold_key`/`*_batch`/`teach_*`），确保任何情况下都**不会替我打字或发送微信消息**。各 AI 的钩子配置路径见其专属文件。

## 隐私与安全（重要）

- **本仓库为 Public（已由 private 公开）。** 它含真实人名（大连理工老师）与私人聊天记录，公开可见——写入/提交前对敏感内容从严把关、必要时脱敏。
- 聊天内容不主动发送到其他外部服务，不要联网检索其中的人名/单位。
- 涉及金额、合作、承诺、对他人的评价等敏感内容：措辞从严、留余地；拿不准的事实**不要替我编造**，标注「待我确认」。
- 提交前留意不要混入与本仓库无关的他人隐私。
- **提交/推送到远程时**：先读 [git-workflow.md](git-workflow.md)（SSH-over-443 鉴权、Public 脱敏纪律、直提 `main` 等约定）。
