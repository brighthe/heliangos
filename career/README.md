# 职业生命周期

本目录保存随职业阶段变化的任职身份、聘期、行政节点、考核要求和出站安排。它们属于个人职业管理事实，不属于稳定的个人简介，也不属于科研知识正文。

## 信息边界

| 内容 | 事实源 |
| --- | --- |
| 稳定身份、背景、对外口径与简历 | [`profile/`](../profile/) |
| 任职、聘期、考核、出站与行政待办 | 当前目录 |
| 联系人关系、聊天原文与沟通证据 | [`wechat/contacts/`](../wechat/contacts/) |
| 科研路线、技术进展与工作汇报 | `dut-postdoc` |
| 研究院任务、计划与项目进度 | `dut-institute-work` |

## 当前档案

- [大连理工大学博士后](dlut-postdoc/README.md)：身份、聘期、考核、科研积分和开放事项。

## 原始材料

GitHub 保存结构化事实、维护规则和来源指针；`.doc`、`.docx`、签章 PDF、扫描件、图片等原始材料保存在 iCloud。引用统一写为：

```text
iCloudDrive:<relative-path>
```

不要写入 `C:\Users\<用户名>\iCloudDrive\...` 等机器相关绝对路径，也不要把原始材料复制进本目录。
