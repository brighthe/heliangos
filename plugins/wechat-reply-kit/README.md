# wechat-reply-kit

面向**微信工作沟通**（与老师、同事、合作方）的 Claude Code 插件。把 `heliangos` 仓库 `.claude/` 中的回复助手能力打包为可在其他仓库复用的插件。

> **定位：参考样板（reference template）。** 本仓库日常使用走 live 配置（`.claude/`）即可；本插件保留下来主要作为"如何把一套命令/子代理/技能打包成可安装插件"的**示例**，以及将来跨仓库复用的起点。**它不保证与 `.claude/` 始终逐字同步**——正式分发前请先比对 `.claude/` 取最新版本。

## 包含能力

| 类型 | 名称 | 作用 |
| --- | --- | --- |
| 技能 | `wechat-work-style` | 微信工作沟通家族写作风格（语气分寸、分段节奏、称呼敬语、软化技巧），编辑回复时自动加载 |
| 子代理 | `intent-analyst` | 拆解对方消息的真实来意、隐含期待、紧急度、该不该答应 |
| 子代理 | `reply-reviewer` | 回复草稿得体性深审（分寸/承诺/风险/完整性） |
| 命令 | `/draft-reply` | 起草回复 |
| 命令 | `/log-chat` | 把一段聊天按统一格式记入对应联系人文件 |

> 注：插件内的子代理/命令默认引用 `wechat/teachers/` 与 `profile/` 等路径，是为 `heliangos` 仓库定制的；在其他仓库复用时按该仓库的目录调整这些路径引用即可。

## 安装

本仓库根目录已是一个本地插件市场（`.claude-plugin/marketplace.json`）。在交互式 `claude` 终端中：

```
/plugin marketplace add .          # 把本仓库注册为插件市场（在仓库根目录执行）
/plugin install wechat-reply-kit   # 安装本插件
```

在其他仓库复用时，把市场地址换成本仓库的 git 地址或本地路径即可。

## live 配置 vs 插件包

- `.claude/`（仓库根）是 **live 配置**：克隆即生效，无需安装。Hook（只起草约束）也在这里。
- `plugins/wechat-reply-kit/`（本目录）是**打包形态**：自包含、可分发，用于在**其他**仓库复用同一套能力。
- 两者当前内容一致，但插件作为参考样板留存，**不强制随 live 同步更新**。
