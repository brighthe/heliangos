用 computer-use 截取并归档指定老师的微信聊天记录。

老师：$ARGUMENTS

步骤：

1. **定位档案**：找到 `wechat/大连理工大学博士后/teachers/<该老师>.md`。若不存在，先用 `_TEMPLATE.md` 建档并在子模块 README 登记。
2. **截取**（computer-use，仅读取）：
   - 先 `request_access` 申请微信所在应用权限，`screenshot` 看当前画面，必要时 `left_click` 点开这位老师的会话、用 `scroll` 向上滚动加载更早消息，逐屏 `screenshot`。
   - **只截图、点会话、滚动**。绝不 `type`/`key` 或批量输入——Hook 会拦截，你也不应尝试替我发送任何消息。
3. **转写**：把截图内容逐条转写成文字，**追加**到该老师 `.md` 的「聊天记录」段末尾，格式 `YYYY-MM-DD　[老师]/[我]：内容`：
   - 忠实转写，不改写原话；语音/图片/转账等非文字内容写成简短摘要并标「（语音/图片/转账摘要）」。
   - 日期以截图中可见的时间为准；不确定标「日期待补」，不要编造。
   - 与已有记录去重，只追加新增部分。
4. **存截图**：把原始截图保存到 `wechat/大连理工大学博士后/screenshots/<该老师>/YYYY-MM-DD-n.png`。
5. **回报**：新增几条、时间范围、是否有需要我跟进的未决事项；若聊天透露新口径或称呼变化，提示我更新档案。

注意：这是写入 Private 仓库的私密资料，只动这位老师的文件与截图目录，不外发、不联网检索其中人名。
