# 微信沟通模块（wechat）

存储我与工作对象的微信聊天记录、每位对象的沟通口径，并在此基础上协助我起草回复。聊天记录按**阶段/场景**分子模块归档。

## 目录结构

```
wechat/
├── README.md                       # 本说明
└── 大连理工大学博士后/              # 子模块：我在大工做博士后期间与相关老师的沟通
    ├── README.md
    ├── teachers/
    │   ├── _TEMPLATE.md            # 新建老师档案的模板（复制它）
    │   └── <姓名>.md               # 每位老师一个文件：档案 + 口径 + 聊天记录
    └── screenshots/                # 截取的原始聊天截图（按老师/日期归档，备查）
```

将来若有别的阶段或单位的沟通，在 `wechat/` 下再开一个同构的子模块即可。

## 两类工作

### 1. 截取聊天记录（computer-use，允许）

用 `/capture-chat` 让 Claude 通过 computer-use **截图**当前微信会话，然后：

- 把截图**转写成文字**，按统一格式追加到对应老师 `.md` 的「聊天记录」段（这是可搜索的资产）；
- 原始截图另存到 `<子模块>/screenshots/<老师>/YYYY-MM-DD-n.png` 备查。

> **安全底线**：computer-use 只用于截图、点开会话、滚动浏览。**Claude 不会替你打字或发送消息**——键盘输入/批量动作已被 Hook 拦截（见仓库 [CLAUDE.md](../CLAUDE.md)「Hook」）。

### 2. 起草回复（只起草，你自己发）

用 `/draft-reply`。Claude 读这位老师的档案与历史聊天 → 必要时用 `intent-analyst` 拆来意 → 按 `wechat-work-style` 起草草稿 → **你自己复制发送**。重要回复发出前可用 `reply-reviewer` 审一遍。

## 隐私

本模块内容高度敏感（真实人名 + 私聊截图）。仓库须保持 Private；聊天原文/截图不外发、不联网检索。
