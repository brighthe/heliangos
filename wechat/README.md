# 微信沟通模块（wechat）

存储我与**大连理工大学各位老师**的微信聊天记录、每位老师的沟通口径，并在此基础上协助我起草回复。

## 目录结构

```
wechat/
├── README.md                 # 本说明
└── teachers/
    ├── _TEMPLATE.md          # 新建老师档案的模板（复制它）
    └── <姓名或拼音>.md        # 每位老师一个文件：档案 + 口径 + 聊天记录
```

**一位老师一个文件**，把这位老师的「人物档案 / 沟通口径 / 聊天记录」放在一起，方便 Claude 一次性读全上下文。

## 工作流

1. **建档**：复制 [teachers/_TEMPLATE.md](teachers/_TEMPLATE.md) 为 `teachers/<姓名>.md`，填好称呼、身份、关系、沟通口径。
2. **记录聊天**：把新的一来一回粘贴给 Claude，用 `/log-chat` 追加到该老师文件的「聊天记录」段（统一格式：日期 + 谁说 + 内容）。
3. **起草回复**：老师发来消息时，用 `/draft-reply`。Claude 会：
   - 读这位老师的档案与历史聊天，理解关系与上下文；
   - 必要时先用 `intent-analyst` 拆解老师的真实来意；
   - 按 `wechat-work-style` 起草 1–2 版回复草稿。
4. **审校**（重要/敏感回复）：委派 `reply-reviewer` 做得体性深审，再发。
5. **我自己复制、发送**——Claude 全程只产出草稿，不直接操作微信。

## 命名约定

- 文件名用老师姓名或拼音，必要时加单位/课题组区分（如 `张伟-力学系.md`）。
- 文件内称呼字段记录「我该怎么称呼他」和「他怎么称呼我」，避免回复时叫错。

## 隐私

本模块内容高度敏感（真实人名 + 私聊）。仓库须保持 Private；聊天原文不外发、不联网检索。
