# Dalian University of Technology Postdoc（子模块）

存放我在**大连理工大学做博士后期间**与相关老师的微信聊天记录、沟通口径与回复协助。

## 内容

- `teachers/<姓名>.md` —— 每位老师一个文件：**人物档案 + 关键信息 + 当前未决 + 聊天记录**（格式见 [_TEMPLATE.md](_TEMPLATE.md)）。只存文字，不保存截图。
- **边界约定**：研究院工作的正文（任务拆解、阶段计划、进度）以 `dut-institute-work` 仓库为单一事实来源（`hpc/plan.md`、`hpc/log.md`）。老师档案里只保留**沟通层面的未决**（等对方答复的、答应对方的事）和指向该仓库的一句话指针；`/log-chat` 转写后如出现工作安排正文，更新到 `dut-institute-work`，不在档案里展开。
