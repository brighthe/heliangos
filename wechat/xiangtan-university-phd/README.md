- `contacts/<姓名>.md` —— 每位联系人一个文件：**人物档案 + 关键信息 + 当前未决 + 聊天记录**（格式见 [_TEMPLATE.md](_TEMPLATE.md)）。只存文字，不保存截图。

## 用法

- 记录聊天：把与某位联系人的微信截图（或文字）发给 Claude，`/log-chat <姓名>` → 转写进对应 `contacts/<姓名>.md`（不存截图）。
- 起草回复：`/draft-reply <姓名> <对方发来的消息>`。

## 隐私

本模块含博士期间真实人名、师生/同门关系与私人聊天记录；仓库为 Public、公开可见。写入前对敏感内容从严把关，必要时脱敏；聊天原文不主动外发到其他服务、不联网检索人名/单位。
