# 高校求职（子模块）

存放我**求职高校教职期间**与各目标高校（学院、人事处、相关老师）的微信聊天记录、沟通口径与回复协助。和 `dalian-university-of-technology-postdoc` 子模块同构，但按**学校**再分一层，每校一个文件夹、校内按联系人分档。

## 目录结构

```
高校求职/
├── README.md                    # 本说明
├── _TEMPLATE.md                 # 新建联系人档案的模板（复制它，全校共用）
├── 湖南理工大学/
│   ├── README.md                # 本校概况 + 联系人索引
│   └── contacts/<姓名>.md       # 每位联系人一个文件
├── 湖南工程学院/
│   ├── README.md
│   └── contacts/<姓名>.md
├── 长沙师范学院/
│   ├── README.md
│   └── contacts/<姓名>.md
└── 湖南警察学院/
    ├── README.md
    └── contacts/<姓名>.md
```

## 两类工作

和微信模块整体一致：

1. **记录聊天**：把与某联系人的微信截图（或文字）发给 Claude，`/log-chat <姓名>` → 转写追加进对应 `contacts/<姓名>.md`（**只存文字，不存截图**）。
2. **起草回复**：`/draft-reply <姓名> <对方发来的消息>` → Claude 读该联系人档案与历史起草草稿，**由我自己发送**。

## 隐私

本模块含真实人名与私聊、且涉及求职/offer 等敏感信息；仓库为 Public、公开可见，聊天原文不主动外发到其他服务、不联网检索校名/人名。涉及 offer、待遇、人才政策、承诺等：措辞从严、留余地、必要时脱敏，拿不准的事实标注「待我确认」。
